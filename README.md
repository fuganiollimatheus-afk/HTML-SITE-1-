# Minha Biblioteca de Lógica e Infraestrutura 🚀

Este repositório foi criado como parte dos meus estudos no **IFSP**, focado em dominar a lógica de programação e fundamentos de TI. O objetivo principal é construir uma base de conhecimento própria, reduzindo a dependência de IAs e consolidando o aprendizado prático.

## 🧠 Conceito: "Pegar o Avançado e fazer o Básico"
A ideia deste projeto é decompor conceitos complexos de infraestrutura e economia em algoritmos simples de JavaScript, utilizando matemática básica e lógica booleana.

## 🛠️ O que tem aqui?

### 1. Validação de Segurança (`validacao.js`)
Aplica lógica condicional (`if/else`) para simular o controle de acesso a um servidor, baseando-se em idade e permissões de administrador.

### 2. Cálculo de ROI Financeiro (`calculo_roi.js`)
Script voltado para o meu Projeto Integrador (Economia/Liberalismo). Calcula o Retorno sobre Investimento de ativos de hardware para análise de eficiência.

### 3. Gestão de Inventário de Hardware (`hardware.js`)
Usa estruturas de dados (Arrays) para organizar e listar componentes de infraestrutura, simulando um controle de estoque técnico.

### 4. Conversor de Unidades de Dados (`conversor.js`)
Um utilitário para transformar Megabytes (MB) em Gigabytes (GB), essencial para cálculos de armazenamento em servidores.

## 📚 Conexão com a Teoria
Estes scripts automatizam conceitos vistos nas aulas de:
- **Informática Básica:** Manipulação de arquivos e hardware.
- **Matemática Aplicada:** Operações de porcentagem e conversão de base.
- **Lógica de Programação:** Estruturas de decisão e repetição.
